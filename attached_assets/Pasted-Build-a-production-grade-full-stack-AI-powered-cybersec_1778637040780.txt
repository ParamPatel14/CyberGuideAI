Build a production-grade full-stack AI-powered cybersecurity assistance web application named “CyberGuide AI”.

Tech Stack:
- Frontend: React + Vite + Tailwind CSS
- Backend: Python FastAPI
- Frontend Routing: React Router
- API Communication: Axios
- Icons: lucide-react
- Animations: Framer Motion
- OCR Support: EasyOCR
- AI Integration Ready: OpenAI/Gemini compatible architecture
- No database for now
- No authentication for now

Application Purpose:
CyberGuide AI helps cyber fraud victims understand what steps to take after being scammed.

The application should:
1. Allow users to report cyber fraud incidents
2. Analyze fraud reports using AI-ready architecture
3. Generate emergency response steps
4. Generate cybercrime complaint guidance
5. Generate document/evidence checklist
6. Estimate recovery probability
7. Generate FIR and bank complaint drafts
8. Extract information from uploaded screenshots using OCR
9. Display scam awareness dashboard
10. Provide production-grade UI/UX

IMPORTANT:
This is NOT a simple demo app.
Generate clean, modular, scalable, production-quality architecture.
